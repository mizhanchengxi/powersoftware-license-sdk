# 客户端软件授权接入指南（v3）

> 适用于：在幂栈网发布客户端软件，集成授权 SDK 实现版本控制与付费功能拦截。
> SDK 仓库：[github.com/mizhanchengxi/powersoftware-license-sdk](https://github.com/mizhanchengxi/powersoftware-license-sdk)
> 关联文档：[授权 SDK 规范](授权SDK规范_v3.md) ｜ [售卖方式与授权购买链路](售卖方式与授权购买链路_v3.md)

## 一、两种接入场景

幂栈网为客户端软件提供两种授权接入方式，开发者根据自身情况选择：

| | 场景 A：平台完整链路（先用后付） | 场景 B：订单不在平台 |
|---|---|---|
| **适用产品** | 客户端软件 + `TRIAL_FIRST` 售卖方式 | 客户端/服务端软件，自行收款 |
| **谁管收款** | 幂栈网平台（支付宝 / PayPal） | 开发者自己（软件内支付或其他渠道） |
| **谁管发码** | 平台支付成功后自动发码 | 软件调平台 API 发码（HMAC 签名） |
| **需要 `apiSecret`？** | ❌ 不需要 | ✅ 需要（仅存服务端，不可存客户端） |
| **需要服务端？** | ❌ 不需要，纯客户端即可 | ✅ 需要（保管 `apiSecret`，转发发码请求） |
| **试用授权** | ✅ 支持（`claimTrial`） | ❌ 无试用 |
| **购买页** | 平台提供，SDK 一行跳转 | 无平台购买页，开发者自行处理 |

### 如何选择

- **你是独立开发者 / 小团队，没有自己的服务端** → 选 **场景 A**
- **你已有支付渠道（如微信/支付宝商户），只想用平台发码校验** → 选 **场景 B**

## 三、场景 A：平台完整链路（先用后付）

### 3.1 前置条件

1. 在幂栈网发布产品，售卖方式选 **先用后付（TRIAL_FIRST）**
2. 填写试用天数（如 7 天）
3. 配置授权版本（edition），建议：
   - `BASIC` — 基础版（免费功能）
   - `PLUS` — 高阶版
   - `ULTIMATE` — 旗舰版
4. 记下 `productUniqueCode`（发布页可见，非密钥）

### 3.2 初始化

**不需要 `apiSecret`**。`apiSecret` 仅用于场景 B 的发码签名，场景 A 完全不涉及。

```python
# Python
from ps_license_sdk import LicenseClient, machine_code

client = LicenseClient(product_unique_code="PRO-2026-001", api_secret="")  # api_secret 留空
mc = machine_code()
```

```javascript
// Node.js
import { LicenseClient, machineCode } from '@mizhanchengxi/ps-license-sdk';

const client = new LicenseClient({ productUniqueCode: 'PRO-2026-001', apiSecret: "" });
const mc = machineCode();
```

```java
// Java
import com.powersoftware.sdk.LicenseClient;

LicenseClient client = new LicenseClient("PRO-2026-001", "");  // apiSecret 留空
String mc = LicenseClient.machineCode();
```

### 3.3 完整接入流程

```
首次启动
    │
    ├─ claimTrial(machineCode) ──────────────────→ 获取试用授权
    │     ↓ 返回 { licenseCode, activationToken }
    │     ↓ 本地持久化存储
    │
    ├─ 试用期内：所有功能可用
    │     │
    │     └─ 点击付费功能 → verifyCached() 60s 缓存校验 → 放行
    │
    └─ 试用到期 / 未激活
          │
          ├─ verifyCached() 返回 invalid/expired
          ├─ 弹窗提示"需要购买激活授权"
          └─ purchaseUrl(machineCode) → 跳转平台购买页
                │
                ↓ 用户在平台支付
                │
                ↓ 平台发码 + 邮件送达
                │
          用户回到软件，输入授权码
                │
                ├─ activate(licenseCode, machineCode)
                │     ↓ 返回 { activationToken }
                │     ↓ 本地持久化存储
                │
                └─ 后续使用 → verifyCached() 校验 → 放行
```

### 3.4 核心代码

```python
import json
from pathlib import Path
from ps_license_sdk import LicenseClient, machine_code

# ---------- 初始化 ----------
client = LicenseClient(product_unique_code="PRO-2026-001", api_secret="")
CRED_FILE = Path.home() / ".myapp" / "license.json"

def load_cred():
    if CRED_FILE.exists():
        return json.loads(CRED_FILE.read_text())
    return {}

def save_cred(d):
    CRED_FILE.parent.mkdir(parents=True, exist_ok=True)
    CRED_FILE.write_text(json.dumps(d, ensure_ascii=False))

# ---------- 首次启动：领取试用 ----------
def claim_trial():
    mc = machine_code()
    try:
        result = client.claim_trial(mc)
        save_cred({
            "licenseCode": result["licenseCode"],
            "activationToken": result["activationToken"],
        })
        print(f"试用已激活，授权码：{result['licenseCode']}")
    except Exception as e:
        print(f"领取试用失败：{e}")

# ---------- 校验授权（点击付费功能时调用） ----------
def check_license(required_edition="PLUS"):
    cred = load_cred()
    if not cred.get("licenseCode"):
        return {"valid": False, "reason": "未激活"}

    mc = machine_code()
    try:
        result = client.verify_cached(
            cred["licenseCode"], mc, cred["activationToken"]
        )
        if not result.get("valid"):
            return {"valid": False, "reason": "授权无效或已过期"}

        user_edition = result.get("edition", "")
        levels = {"BASIC": 0, "PLUS": 1, "ULTIMATE": 2}
        if levels.get(user_edition, 0) < levels.get(required_edition, 0):
            return {"valid": False, "reason": f"需要 {required_edition} 及以上版本"}

        return {"valid": True, "edition": user_edition,
                "expiryTime": result.get("expiryTime")}
    except Exception as e:
        return {"valid": False, "reason": str(e)}

# ---------- 激活授权码（用户购买后输入） ----------
def activate(license_code):
    mc = machine_code()
    try:
        result = client.activate(license_code, mc)
        save_cred({
            "licenseCode": license_code,
            "activationToken": result["activationToken"],
        })
        return True
    except Exception as e:
        print(f"激活失败：{e}")
        return False

# ---------- 跳转购买页 ----------
def open_purchase_page():
    mc = machine_code()
    url = client.purchase_url(mc)
    import webbrowser
    webbrowser.open(url)
```

### 3.5 功能拦截示例

```python
# 定义功能版本要求
FEATURE_EDITION = {
    "basic_feature":   "BASIC",
    "plus_feature":    "PLUS",
    "ultimate_feature": "ULTIMATE",
}

def run_feature(feature_name):
    required = FEATURE_EDITION.get(feature_name, "BASIC")
    if required == "BASIC":
        do_basic_feature()
        return

    result = check_license(required)
    if result["valid"]:
        do_paid_feature(feature_name)
    else:
        print(f"无法使用此功能：{result['reason']}")
        open_purchase_page()
```

## 四、场景 B：订单不在平台

### 4.1 前置条件

1. 在幂栈网发布产品，授权码功能开启（`licenseEnabled = true`）
2. 在开发者后台获取 `licenseApiSecret`（**仅存服务端，不可泄露到客户端**）
3. 记下 `productUniqueCode`

### 4.2 架构

```
客户端                        你的服务端                      幂栈网平台
  │                              │                              │
  │  用户付费（你的支付渠道）      │                              │
  ├─────────────────────────────→│                              │
  │                              │  generateForSoftware(        │
  │                              │    machineCode, edition,     │
  │                              │    clientOrderId)            │
  │                              │  (HMAC 签名 + timestamp)      │
  │                              ├─────────────────────────────→│
  │                              │                              │
  │                              │  ← 返回 licenseCode          │
  │  ← 返回 licenseCode         │                              │
  │                              │                              │
  │  activate(licenseCode, mc)   │                              │
  ├────────────────────────────────────────────────────────────→│
  │  ← 返回 activationToken     │                              │
  │                              │                              │
  │  verifyCached(...)          │                              │
  ├────────────────────────────────────────────────────────────→│
  │  ← { valid, edition, expiryTime }                          │
```

### 4.3 核心代码

**服务端（保管 apiSecret）：**

```python
from ps_license_sdk import LicenseClient, machine_code

server_client = LicenseClient(
    product_unique_code="PRO-2026-001",
    api_secret="你的发码密钥_FROM_DEVELOPER_CONSOLE",
)

def issue_license(user_machine_code, edition="PLUS", order_id=""):
    """用户付款后，服务端调平台发码"""
    result = server_client.generate_for_software(
        machine_code_value=user_machine_code,
        edition=edition,
        expiry_days=365,
        client_order_id=order_id,
    )
    return result["licenseCode"]
```

**客户端（不需要 apiSecret）：**


## 五、SDK 方法速查

| 方法 | 场景 A | 场景 B | 签名 | 说明 |
|---|:---:|:---:|:---:|---|
| `machine_code()` | ✅ | ✅ | — | 生成机器码（跨语言一致） |
| `claim_trial(mc)` | ✅ | — | — | 领取试用授权（仅先用后付产品） |
| `activate(code, mc)` | ✅ | ✅ | — | 激活授权码，绑定机器 |
| `verify(code, mc, token)` | ✅ | ✅ | — | 校验授权状态 |
| `verify_cached(code, mc, token)` | ✅ | ✅ | — | 带本地缓存（60s）的校验 |
| `deactivate(code, mc)` | ✅ | ✅ | — | 解绑机器（需登录，浏览器场景） |
| `purchase_url(mc)` | ✅ | — | — | 生成平台购买页 URL |
| `generate_for_software(mc, edition, ...)` | — | ✅ | HMAC | 软件内发码（仅服务端） |
| `upgrade_for_software(code, edition, ...)` | — | ✅ | HMAC | 软件内升级/续费（仅服务端） |

## 六、本地凭证存储规范

SDK 本身不负责持久化，由开发者自行实现。存储内容：

```json
{
  "licenseCode": "XXXXXXXXXXXX",
  "activationToken": "YYYYYYYYYYYY",
  "lastVerify": {
    "valid": true,
    "edition": "ULTIMATE",
    "expiryTime": 1735689600000,
    "cachedAt": 1735689600000
  }
}
```

**原则：**
- 只存 `licenseCode` + `activationToken` + 最近一次 verify 结果
- 不存可解密的完整授权信息（防逆向无意义，只作缓存）
- `verifyCached` 的 60s 缓存在 SDK 进程内，重启后失效，需重新调 `verify`

## 七、版本层级对比

开发者自定义 edition code（如 `BASIC` / `PLUS` / `ULTIMATE`），在平台发布页配置。客户端校验时按层级比较：

```python
EDITION_LEVEL = {"BASIC": 0, "PLUS": 1, "ULTIMATE": 2}

def edition_sufficient(user_edition, required_edition):
    return EDITION_LEVEL.get(user_edition, 0) >= EDITION_LEVEL.get(required_edition, 0)
```

常见映射（参考）：

| 功能档位 | edition code | 层级 | 典型功能 |
|---|---|---|---|
| 基础版 | `BASIC` | 0 | 基础修图、格式转换 |
| 高阶版 | `PLUS` | 1 | 批量处理、高清放大 |
| 旗舰版 | `ULTIMATE` | 2 | AI 修复、封面助手 |

> 版本名称和 code 由开发者在平台自定义，不强制叫 BASIC/PLUS/ULTIMATE。

## 八、错误码处理

SDK 抛出 `LicenseError`，携带 `error_code` 属性：

```python
from ps_license_sdk import LicenseError

try:
    result = client.verify_cached(...)
except LicenseError as e:
    if e.error_code == "expired":
        open_purchase_page()
    elif e.error_code == "revoked":
        show_message("授权已被吊销，请联系客服")
    elif e.error_code == "machineLimit":
        show_message("已达机器绑定上限，请在个人中心解绑旧设备")
    elif e.error_code == "NETWORK_ERROR":
        show_message("网络异常，请检查网络后重试")
    else:
        show_message(f"校验失败：{e}")
```

| 错误码 | 含义 | 客户端建议处理 |
|---|---|---|
| `codeNotFound` | 授权码不存在 | 检查输入 |
| `revoked` | 已吊销 | 提示联系客服 |
| `expired` | 已过期 | 引导购买/续费 |
| `machineLimit` | 机器绑定数已满 | 引导去个人中心解绑 |
| `tooManyAttempts` | 触发限流 | 提示稍后重试 |
| `trialNotEnabled` | 产品未开启试用 | 检查平台配置 |
| `NETWORK_ERROR` | 网络/超时 | 离线宽限或提示重试 |

## 九、购买页跳转与站点选择

### 9.1 购买页 URL

```text
https://www.powersoftware.app/product/license/purchase?productUniqueCode={productUniqueCode}&machineCode={machineCode}
```

SDK 方法：

```python
url = client.purchase_url(mc)
url = client.purchase_url(mc, base="https://www.powersoftware.cn")
```

### 9.2 购买站选择：`.app`（国际站） vs `.cn`（国内站）

| | `powersoftware.app`（国际站） | `powersoftware.cn`（国内站） |
|---|---|---|
| 支付方式 | 支付宝 + PayPal | 仅支付宝 |
| 国家/币种 | Cloudflare 按 IP 自动识别（CN→CNY，其余→USD） | 固定 `country=CN`，人民币 |
| 语言 | 按 URL 前缀 / `Accept-Language` 自动检测 | 固定 `zh-CN` |
| 适用用户 | 国际用户 / 海外 | 中国大陆用户 |

**SDK 默认 `.app`，不做自动判断。** 客户端软件需自行决定传哪个 `base`。

#### 判断方式

**方式一：按系统语言（推荐）**

```python
import locale

def get_purchase_base():
    sys_lang = locale.getdefaultlocale()[0] or ""
    if sys_lang.startswith("zh"):
        return "https://www.powersoftware.cn"
    return "https://www.powersoftware.app"
```

```javascript
function getPurchaseBase() {
    const lang = process.env.LANG || "";
    return lang.toLowerCase().startsWith("zh")
        ? "https://www.powersoftware.cn"
        : "https://www.powersoftware.app";
}
```

```java
String getPurchaseBase() {
    return "zh".equals(Locale.getDefault().getLanguage())
        ? "https://www.powersoftware.cn"
        : "https://www.powersoftware.app";
}
```

**方式二：用户设置项** — 设置界面提供"地区"选项，用户自行选择。

**方式三：硬编码** — 仅面向国内用户的软件直接写死 `base="https://www.powersoftware.cn"`。

> 详见 [语言与国家逻辑](语言与国家逻辑_v3.md) 第 2.4 节。
